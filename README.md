# Glyphe Atelier

Créateur de polices de caractères et d'écriture **100 % dans le navigateur**.

Dessinez chaque glyphe (lettres, chiffres, ponctuation, tifinagh) avec des guides de métriques (ligne de base, hauteur d'x, capitales, approches), prévisualisez le texte en direct, et exportez vos dessins.

Idéal pour créer une police manuscrite personnelle ou expérimenter des formes de caractères.

## Démo

👉 [https://salimadour31-boop.github.io/glyphe-atelier/](https://salimadour31-boop.github.io/glyphe-atelier/)

## Fonctionnalités

- Grille de caractères : A-Z, a-z, 0-9, ponctuation de base + alphabet tifinagh
- Canvas de dessin (souris / tactile) avec stylo et gomme
- Guides : baseline, x-height, cap-height, side bearings
- Annuler, effacer le glyphe courant
- Aperçu de texte en direct (utilise les glyphes dessinés)
- Export PNG / SVG par glyphe
- Export projet JSON (tous les glyphes)
- Interface multilingue : Français, English, Taqbaylit
- Thème clair / sombre
- Rien n'est envoyé au serveur — 100 % local

## Usage

1. Ouvrez la démo.
2. Choisissez un caractère dans la grille.
3. Dessinez-le en respectant les guides.
4. Répétez pour les autres.
5. Tapez un texte dans l'aperçu.
6. Exportez.
